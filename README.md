# ROIL UI Components

A small project I made to get more practice with React, TypeScript, and building reusable components. I also wanted to learn more about accessibility and how to keep UI designs consistent.

I used colors from ROIL, a dirt bike app I'm working on.

## Features

- Buttons with different styles and disabled states
- Username input with basic validation
- Rider Card that updates when you follow a rider or change the username
- Shared CSS colors and styles
- Keyboard focus styles and a layout that works on smaller screens

## Built With

- React
- TypeScript
- CSS
- Vite

## How to Run

1. Run `npm install` to install the dependencies.
2. Run `npm run dev` to start the project.
3. Open the local URL in your browser.

This is just a practice project and isn't connected to the actual ROIL app.
